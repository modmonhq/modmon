# Shell completions

These files are generated from the public Clap tree by
`./scripts/generate-artifacts.sh`. Do not edit them directly. Internal commands
are removed before Bash, Zsh, Fish, PowerShell, and Elvish generation.

Package installers should place the matching file in the shell's system
completion directory. For a per-user install, follow that shell's documented
completion path; do not source a completion for a different `mm` release.
